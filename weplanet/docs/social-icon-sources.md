# 소셜 로그인 아이콘 출처

로그인·회원가입 화면은 아래 공식 리소스를 로컬 정적 파일로 제공합니다.

- `google.png`: [Google 로그인 디자인 가이드](https://developers.google.com/identity/branding-guidelines)의 [공식 G 아이콘](https://developers.google.com/static/identity/images/g-logo.png).
- `kakao.svg`: [카카오 공식 로그인 버튼 SVG](https://developers.kakao.com/tool/images/resource/preview/login-simple-ko.svg)의 말풍선 경로를 그대로 사용하고 노란색 아이콘 배경을 추가했습니다. [카카오 디자인 가이드](https://developers.kakao.com/docs/ko/kakaologin/design-guide).
- `line.png`: [LINE 공식 홈페이지의 32px 파비콘](https://www.line.me/static/img/favicon-32x32.png).

각 서비스의 로고 및 상표 권리는 해당 서비스에 있습니다.
